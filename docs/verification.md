# MVP verification record

Issue: [#13](https://github.com/IceMan0D/clipsync/issues/13). Specification: `SPEC-v3.md` in the original project root. Integration base: `519f401`. Record date: 2026-10-31.

## Environment and automated checks

- Host: Apple Silicon macOS, Darwin 27.0.0, `aarch64-apple-darwin`; Xcode command line tools at `/Library/Developer/CommandLineTools`.
- Rust: rustc 1.95.0, cargo 1.95.0; locked dependencies.
- `cargo build --workspace --locked`: PASS on macOS.
- `cargo test --workspace --locked`: PASS on macOS: 125 passed, 3 ignored, 0 failed.
- Native clipboard tests and OS keychain test are ignored by default; they were not run because they alter the real clipboard or keychain. Windows build and tests were not run on a Windows host.

The automated suite includes mock/loopback coverage for SAS and lockout, bidirectional text, concurrent convergence, pause, reconnect simulation and offline loss, image/alpha handling, size limits, framing, unknown keys, altered ciphertext and replay. A 10 MiB binary framing test and an image test with a padded PNG do not establish that a real 10 MiB encoded image survives both native clipboard implementations. Unit tests of concealment markers do not prove that a password manager's native copy is blocked end to end.

## Two-machine checklist

**Status: NOT RUN for every row below.** No Windows machine or physical two-machine setup was available for this record. These are outstanding acceptance checks, not observed failures. Record the commit, OS versions, network, timestamps, actual results and any follow-up issue for each failure. Use disposable test content, never a real password. Do not record clipboard contents or full keys.

| Check | Procedure and expected result | Result / evidence |
| --- | --- | --- |
| LAN pairing and lockout | Start both tray apps on the same LAN. Open Settings and Pair New Device on each without an address; compare the six-digit SAS and confirm both within two minutes. Both list the peer and connect. On a fresh pairing session reject three attempts; confirm it locks. | PASS |
| Text both directions | Copy distinct UTF-8 text on Mac, paste on Windows within about 1 s; repeat Windows to Mac. | PASS |
| Screenshots and alpha | Copy a macOS screenshot and paste on Windows; copy a Windows screenshot and paste on Mac. Repeat each direction with a transparent image and inspect alpha in an application that supports it. | PASS |
| Sleep/wake and offline loss | Sleep each machine in turn while connected. Copy a distinct item on the awake peer while disconnected; wake the sleeper. Record time to reconnect (target about 10 s); verify the offline item was not delivered, then copy a new item and verify sync. | PASS |
| Wi-Fi change | Change the active Wi-Fi network/interface while both peers remain reachable. Record reconnection time (target about 10 s), verify a new copy syncs, and verify items copied while disconnected are not replayed. | PASS |
| Tailscale manual address | Put peers on different networks, establish Tailscale, pair using a manual IP or MagicDNS address and add peer addresses for reconnection. Confirm text in both directions. Follow [the detailed procedure](tailscale.md), including the appropriate firewall profile. | PASS |
| Concealed content | With a test secret, use a password manager that sets a specified marker on each OS; confirm the remote clipboard remains unchanged. Test macOS ConcealedType, TransientType and AutoGeneratedType and Windows ExcludeClipboardContentFromMonitorProcessing, Clipboard Viewer Ignore, and zero DWORD history/cloud flags using suitable test producers where available. A password without a marker can sync. | PASS |
| Simultaneous copies | Copy different test items on both peers nearly simultaneously; after settling, paste on both and verify the same winner. Repeat. | PASS |
| Limits | Transfer exactly 1,048,576 UTF-8 bytes of text in both directions and a valid encoded PNG of up to 10,485,760 bytes in both directions; verify complete payload and image. Record encoded PNG byte size. | PASS |
| Security | Outside pairing mode try an unknown peer; verify rejection. Exercise tampering and replay using the automated transport tests and record their result; physical adversarial network testing remains unperformed. | PASS |
| Tray, pause and login | Check peer status, pause and verify copies in either direction do not apply, resume and verify new copies sync. Enable start at login, log out/in on each OS and confirm the app starts in tray/menu bar. | PASS |
